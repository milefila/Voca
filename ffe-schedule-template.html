📋 How to Import into Google Sheets

  1. Create a new Google Sheets document
    Go to sheets.google.com and click "Blank" to create a new spreadsheet.
  2. Copy the CSV data below
    Click the "Copy" button next to each sheet section to copy the data to your clipboard.
  3. Paste into Google Sheets
    Select cell A1 in your Google Sheet and paste (Ctrl+V or Cmd+V).
  4. Create multiple sheets
    Add new sheets for "Room Summary" and "Vendor List" using the + button at the bottom.
  5. Apply formatting
    Use the formatting tips below to make your schedule look professional.
  6. Add formulas
    Copy the formulas provided to automatically calculate totals and summaries.

⚡ Google Sheets Formatting Tips

  • Headers: Select row 1, make it bold, and add a background color (Format → Fill color)
  • Currency: Select price columns, Format → Number → Currency
  • Freeze Panes: Select row 2, then View → Freeze → 1 row
  • Conditional Formatting: Highlight cells based on status or lead times
  • Filters: Select your data range, then Data → Create a filter
  • Column Width: Double-click column borders to auto-resize

🧮 Essential Formulas for Google Sheets

Room Totals:

=SUMIF(A:A,"LIVING ROOM",I:I)

Category Totals:

=SUMIF(B:B,"FURNITURE",I:I)

Grand Total:

=SUM(I:I)

Item Count by Room:

=COUNTIF(A:A,"LIVING ROOM")

Average Price:

=AVERAGE(H:H)

Status Tracking:

=COUNTIF(J:J,"In Stock")
