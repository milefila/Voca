# Voca

Your voice. Structured. Unforgettable.

## What It Does

Voca is a voice-first script tool that turns your lived experience into structured, authentic short-form video scripts in 60–90 seconds. Answer four quick questions about your expertise, and Claude generates a script tailored to your natural voice and communication style.

## Who It Helps

Coaches, consultants, educators, service providers, and midlife career transitioners who want authentic scripts without templates or fluff.

## Live Demo

https://voca-script.lovable.app

Sign up, fill the four voice map questions, and generate your script.

## Built With

- **Frontend:** Lovable (React + Tailwind)
- **Auth:** Supabase
- **AI:** Anthropic Claude API (client-side generation)
- **Voice Input:** Web Speech API (MVP)
