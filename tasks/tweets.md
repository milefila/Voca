Write one thread + 3 standalone tweets from source content.

## Checklist
- [ ] Read source / newsletter draft

## Format Rules
- Thread tweet 1: hook only — no "thread:" label
- Each tweet standalone-readable if pulled out of thread
- No em dashes, no "Exciting news", no lists of 5 every time
- Standalone tweets: one insight, one sentence, optionally one question
